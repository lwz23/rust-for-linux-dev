# C2SafeRust Tooling

This directory stores structured planning and validation artifacts generated by
`scripts/c2saferust/`.

## Purpose

The tool is intended to support artifact-constrained Rust rewrites of Linux
kernel drivers. It does not try to directly emit an unconstrained translation.
Instead, it produces a staged planning surface:

- Kbuild switch plan
- bindings/helper patch plans
- abstraction plan
- unsafe obligation set
- translation plan
- safety policy and soundness discharge
- agent workflow / oracle feedback

## Current Rounds

- `nlmon/`: first `net-link-type` experiment
- `et1011c/`: first `net-phy` reference round target
- later rounds may add additional family/module directories

## Workflow

Typical usage:

```bash
python3 scripts/c2saferust/tool_cli.py refresh-artifacts \
  --module-path drivers/net/phy/et1011c.c

python3 scripts/c2saferust/tool_cli.py verify-safety \
  --module-path drivers/net/phy/et1011c.c \
  --output Documentation/rust/c2saferust/et1011c/safety-verdict.json

python3 scripts/c2saferust/tool_cli.py gate-agent-candidate \
  --module-path drivers/net/phy/et1011c.c \
  --output Documentation/rust/c2saferust/et1011c/agent-gate-report.json
```

For modules whose first smoke step is not an `ip link` lifecycle, the oracle is
selected by the module/scenario profile rather than by hard-coded CLI logic.
